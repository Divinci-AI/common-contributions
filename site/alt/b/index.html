Let AI help keep free software alive.
On the maintainer's terms.

Common AI is building the safety layer first: a harness that keeps an AI's contribution small, capped and in front of a person. It exists and runs as a dry run. You cannot install it yet.

What a task looks like shape of the flow, not a recording

# one task, one file, one cap
check   opt-in file present?        yes
check   kill switch clear?          yes
hold    worst-case spend reserved   ok
call    model (no tools, no shell)
scan    added text for secrets      clean
verify  types + tests               pass
stop    wait for a person to approve   default: no

The bigger bet

If AI changes can be made safe to receive, free software could be kept current by anyone with spare capacity, and a universal catalog could send you to an existing project before you spend a token building another. Those are hopes, not results. Most maintainers are unpaid today and nothing here pays anyone. The catalog does not exist yet.

Common AI is a working title, not cleared as a name, and not affiliated with CommonAI. Self-hosted fonts, no third-party scripts, no tracking. Source (Apache-2.0).
